# Expenvisor - AI Expense Tracker

A modern, AI-powered expense tracking app built with Flutter, featuring voice input, OCR scanning, and intelligent financial insights.

## 🎨 Design System

**Midnight Aurora Color Scheme:**

- Primary: Midnight Blue (#191970)
- Accent: Electric Mint (#00FFA3)
- Secondary: Soft Purple (#A78BFA)
- AI Features: Soft Purple (#A78BFA)

## 🚀 Features (Planned)

### Core Features

- ✅ Beautiful onboarding experience

- ✅ Dark & Light mode support
- ✅ Responsive design system

## 🛠 Tech Stack

- **Framework:** Flutter 3.6+
- **State Management:** Riverpod
- **UI Framework:** Material 3
- **Typography:** Google Fonts (Inter + Poppins)
- **Animations:** flutter_animate
- **Charts:** fl_chart
- **Backend:** Firebase (planned)

## 🏃‍♂️ Getting Started

1. **Prerequisites:**

   ```bash
   flutter --version  # Should be 3.6+
   ```

2. **Install dependencies:**

   ```bash
   flutter pub get
   ```

3. **Run the app:**
   ```bash
   flutter run
   ```

## 📁 Project Structure

